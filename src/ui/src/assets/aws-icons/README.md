# AWS Architecture Icons

The destination-engine icons of the experimental graph explorer (#308), copied
unmodified from the official AWS Architecture Icons asset package.

- Source: the asset package on the AWS Architecture Icons page,
  <https://aws.amazon.com/architecture/icons/>
- Package: `Icon-package_07312026` (the Q3 2026 release, dated 2026-07-31),
  retrieved 2026-11-02
- Files: the 48 px service icons (`Architecture-Service-Icons_07312026`)

| File | Package file | Engine ids |
|---|---|---|
| `amazon-aurora.svg` | `Arch_Databases/48/Arch_Amazon-Aurora_48.svg` | `aurora_mysql`, `aurora_postgresql` (the package has one Aurora service icon; the label names the engine) |
| `amazon-dynamodb.svg` | `Arch_Databases/48/Arch_Amazon-DynamoDB_48.svg` | `dynamodb` |
| `amazon-elasticache.svg` | `Arch_Databases/48/Arch_Amazon-ElastiCache_48.svg` | `elasticache` |
| `amazon-documentdb.svg` | `Arch_Databases/48/Arch_Amazon-DocumentDB_48.svg` | `documentdb` |
| `amazon-opensearch-service.svg` | `Arch_Analytics/48/Arch_Amazon-OpenSearch-Service_48.svg` | `opensearch` |
| `amazon-neptune.svg` | `Arch_Databases/48/Arch_Amazon-Neptune_48.svg` | `neptune` (a catalog placeholder engine) |
| `amazon-keyspaces.svg` | `Arch_Databases/48/Arch_Amazon-Keyspaces_48.svg` | `keyspaces` (reserved for later) |

The package ships no licence or attribution file. The icons are published by
AWS for building architecture diagrams of AWS services; they are used here, in
an AWS-published sample, to identify the AWS service each node stands for, with
the service name always shown beside them. Keep the files unmodified (no
recolouring, cropping or redrawing); to update them, replace them with the
same files from a newer package and update this README.
