# UX audit evidence (2026-11-14)

This branch holds the screenshots and design sketches embedded in the GitHub issues filed from the 2026-11-14 UX audit of the results UI. It is not for merging and shares no history with `main`.

- `screens/`: screenshots of the UI running locally on the synthetic wordpress, discourse and trailgear samples. Files ending `__top` are the top of a very tall page; files ending `__cropped` were cropped.
- `sketches/`: mid-fidelity sketches of the proposed target layouts. They are sketches, not final designs.
