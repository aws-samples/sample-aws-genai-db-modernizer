# Sample report

!!! info "Generated at build time"
    This page is a placeholder. The published site replaces it with a real deterministic assessment of the WordPress sample, rendered by `scripts/build_docs_sample.py` after the site builds (`--llm-mode none`, so no model call and no AWS credentials). Build it locally with:

    ```bash
    uv run python scripts/build_docs_sample.py --site-dir site
    ```

    then open `site/sample/index.html`.

When built, this page links to every rendered deliverable: the decision report, the engineering report, the interactive analysis report, and the executive summary PDF and deck. All of them come from the same `wordpress` sample used throughout [Get started](get-started.md).
